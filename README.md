## Analytical Insight to Improve Fraud Detection 

## Business Overview: 
Within this project, we will take a look at a synthetic dataset of bank transactions for an international bank called Caishen. 
 
## Business Challenge:
The company announced in an all-hands meeting that its goal for the next three years would be to identify fraudulent activity within its customer-facing bank accounts. The objective was to determine which strategies could successfully capture as many fraudulent transactions as possible while minimizing false positives.

## Process: 
This project followed the end-to-end data analytics workflow, from exploratory data analysis to predictive model evaluation. I analyzed a dataset containing more than 6 million financial transactions to identify patterns, detect anomalies, and better understand the characteristics associated with fraudulent activity.

Using Python, I cleaned and explored the data through statistical analysis and visualizations to uncover trends, outliers, and relationships between transaction features. These insights guided feature selection and informed the development of a Random Forest model for fraud detection.

Finally, I evaluated the model's performance using classification metrics and interpreted the results in a business context. The project demonstrated how data analysis and machine learning can work together to support fraud detection, reduce financial risk, and inform data-driven decision-making.

## Tool Stack: 
Platforms: VS Code, Jupyter Notebook
Programming Language: Python 
Python Packages: 
- Exploratory Data Analysis: Pandas, NumPy
- Data Visualization: Matplotlib, Seaborn 
- Evaluation: Sklearn.Metrics
Machine Learning Model: Random Forest

## Outcome: 
Built a fraud detection model that catches significantly more fraudulent transactions, reducing the undetected fraud rate from 29% to 15% compared to the initial baseline. In a real deployment, this kind of improvement would reduce a bank's exposure to financial loss from undetected fraud.
